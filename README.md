# EcoPulse 📈

**EcoPulse** is a professional-grade real-time economic dashboard designed to provide actionable insights into global and regional economic indicators. 

Built with **Python**, **Dash**, and **Plotly**, it offers a responsive and interactive experience for monitoring critical metrics such as GDP growth, inflation, and unemployment.

## 🚀 Key Features

- **Interactive Visualizations**: High-fidelity charts for trend analysis using Plotly.
- **Dynamic Indicators**: Monitor GDP, Inflation, Unemployment, and Consumer Sentiment in real-time.
- **Responsive Design**: Clean UI built with Bootstrap for seamless use across devices.
- **Time-Series Analysis**: Flexible time-range selection for historical data comparison.
- **Commercial Ready**: Optimized for production deployment with Gunicorn support.

## 🛠️ Technology Stack

- **Framework**: Dash (by Plotly)
- **Styling**: Bootstrap 5
- **Data Engine**: Pandas & NumPy
- **Server**: Flask (underlying Dash)

## 📦 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Ali-Marandi/EcoPulse.git
   cd EcoPulse
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the dashboard**:
   ```bash
   python ecopulse.py
   ```
   *The dashboard will be available at `http://127.0.0.1:8050`.*
