# EcoPulse

## Real-time Economic Dashboard

EcoPulse is a real-time economic dashboard designed to provide up-to-date insights into global and regional economic indicators. It integrates data from various financial APIs, visualizes trends, and offers predictive analytics to help users make informed decisions.

### Features:
- Real-time data fetching from economic APIs (e.g., FRED, World Bank).
- Interactive dashboards for visualizing key economic indicators (GDP, inflation, unemployment, etc.).
- Predictive models for short-term economic forecasting.
- Customizable alerts for significant economic events.

### Technologies Used:
- Python
- Flask (for web application)
- Plotly/Dash (for interactive visualizations)
- Pandas (for data manipulation)
- Scikit-learn (for predictive analytics)

### Installation and Usage:

```bash
git clone https://github.com/Ali-Marandi/EcoPulse.git
cd EcoPulse
pip install -r requirements.txt
python ecopulse.py
```
